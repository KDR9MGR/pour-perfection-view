# Complete the mobile website experience

## Goal
Bring every website page up to the same polished phone experience as the homepage, while preserving the BottlesUp logo, fonts, colors, copy, and desktop design. The app preview screens remain unchanged.

## Pages included
- Features
- Events
- VIP Tables
- Venues
- How It Works
- Partners
- Sign In and Promoter Login
- Shared header, menu, footer, page introductions, booking confirmation, and mobile action bar

## What will change
- Tighten mobile spacing and type sizing across page introductions and content sections.
- Add scroll-reveal motion and clearer visual pacing to cards, lists, and calls to action.
- Make event browsing more phone-friendly while preserving the full booking and ticket-confirmation flow.
- Improve VIP tier comparison, venue cards, and step cards for one-handed browsing.
- Compact the sign-in perks and improve the stacked sign-in and partner forms.
- Add clear submitted/success feedback to the early-access and partner forms without adding a backend.
- Ensure all touch targets, fixed controls, bottom spacing, and safe-area behavior work on modern phones.
- Keep desktop layouts intact and avoid changing the app preview screen designs.

## Technical details
- Update shared responsive presentation in `Bits`, `SiteChrome`, and global styles.
- Apply route-specific responsive layouts and existing motion patterns to each website route.
- Reuse existing semantic colors, buttons, cards, and Plus Jakarta Sans typography.
- Verify every route at phone and desktop widths, including menu interaction, form feedback, event booking confirmation, horizontal overflow, and console errors.
